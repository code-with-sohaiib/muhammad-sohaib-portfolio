## Contact Form Integration

The contact form is powered by **Google Apps Script** and **Google Sheets**.

Every submission is automatically stored inside a Google Spreadsheet without requiring a traditional backend or database.

## Workflow

```text
Portfolio Website
        │
        ▼
Google Apps Script
        │
        ▼
Google Sheets
```

Each submission records:

| Field          | Description       |
| -------------- | ----------------- |
| Timestamp      | Date & Time       |
| Full Name      | Visitor Name      |
| Email          | Visitor Email     |
| Service Needed | Selected Service  |
| Message        | Visitor Inquiry   |
| Source         | Portfolio Website |

The form submits asynchronously using the Fetch API, allowing visitors to remain on the website while their inquiry is securely stored in Google Sheets.

### Features

* Client-side validation
* Instant submission
* Automatic success message
* Automatic form reset
* Duplicate submission prevention
* No backend server required
* No database required
